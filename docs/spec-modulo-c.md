## Notas de dirección visual (a respetar desde el primer commit)

- **Minimalismo estricto.** Nada de recursos visuales gratuitos; cada
  elemento (parallax, transición, micro-interacción) debe justificar su
  presencia.
- **Parallax y efectos de scroll con mucha finura.** Si se usan, sutiles,
  bien calibrados (velocidad, easing, distancias cortas) — el objetivo es
  sensación de calidad, no un efecto vistoso o llamativo.
- **Barra alta de UX/UI.** Tratamiento cuidado en tipografía, espaciado,
  transiciones entre estados; nada por defecto ni "de plantilla".
- Coherente con el resto del sitio (panel admin ya tiene una estética propia
  en `src/app/admin` — revisar antes de definir la paleta/tipografía pública).
